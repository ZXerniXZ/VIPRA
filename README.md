# VIPRA
Veicoli Interconnessi per la Prevenzione dei Rischi su Asfalto
Progetto x project day 2024/25, main repository 

# Descrizione
Il progetto prevede un sistema di sicurezza distribuito su veicoli stradali. Ogni auto verrebbe equipaggiata con una telecamera e un sistema di trasmissione, orientati ad allertare il traffico nella corsia opposta, di pericoli incontrati in precedenza. Quando uno dei dispositivi rileva un potenziale pericolo, come un ostacolo improvviso, un incidente o un veicolo che potrebbe rappresentare un rischio, invia immediatamente un segnale in broadcast, ossia in trasmissione aperta, verso tutte le altre auto dotate del sistema nei dintorni.

Le auto in corsa  nella corsia opposta, elaborano l'allarme e lo notificano al conducente tramite un avviso sonoro o visivo, permettendogli di essere informato in tempo reale e di adattare la guida alle condizioni di sicurezza. Il principale obiettivo del progetto è aumentare la sicurezza sulla strada, offrendo un avviso preventivo su potenziali pericoli presenti nella corsia di pertinenza e riducendo così il rischio di incidenti
